Интернет-магазин товаров для студентов-стоматологов, встроенный прямо в Telegram. Пользователь открывает магазин кнопкой в боте, выбирает товары, собирает корзину и оформляет заказ. Заказ приходит в чат бота, менеджер связывается с покупателем в личных сообщениях.

Всё приложение — **один файл `index.html` на чистом JavaScript**: без фреймворков, сборщиков и бэкенда.

## Возможности

- **Каталог с разделами:** фантомные зубы и модели для практических занятий, обложки для документов и другое
- **Карточка товара:** галерея фото, выбор варианта, цена
- **Тиражный калькулятор:** для обложек цена за штуку зависит от материала и тиража (41–200, 201–500, 501–1000 шт.)
- **Корзина:** изменение количества, итоговая сумма, лимит позиций. Сохраняется в `localStorage`
- **Оформление заказа:** через `Telegram.WebApp.sendData()`. Заказ упаковывается в компактный JSON с учётом лимита Telegram на размер данных (4 КБ)
- **Разделы «Скоро»:** анонсы будущих товаров
- **Нативное поведение в Telegram:** системная кнопка «Назад», тактильная отдача (haptic feedback), цвета шапки и фона под тему, раскрытие на весь экран
- **Персонализация:** приветствие по имени пользователя Telegram

## Технические детали

| Задача | Решение |
|---|---|
| Навигация | собственный мини-роутер: объект состояния, функция `go()` и перерисовка через `render()` |
| Рендеринг | шаблонные строки, экранирование пользовательских данных (`esc()`) для защиты от XSS |
| Галереи | автопоиск дополнительных фото по схеме `name-2.jpg`, `name-3.jpg`… без ручного списка |
| Битые изображения | fallback на иконку-заглушку |
| Анимации | CSS-переходы с поэтапным появлением элементов (`--i`) |
| Вне Telegram | страница открывается в обычном браузере, оформление заказа подсказывает открыть бота |

## Запуск

**Локально:** откройте `index.html` в браузере или поднимите статический сервер:

```bash
python -m http.server 8000
```

**В Telegram:**
1. Разместите файлы на любом HTTPS-хостинге, например на GitHub Pages: *Settings → Pages → Deploy from branch → main*.
2. В [@BotFather](https://t.me/BotFather) создайте бота и подключите Mini App: *Bot Settings → Menu Button* (или кнопка `web_app` в клавиатуре бота) со ссылкой на страницу.
3. Обрабатывайте заказы на стороне бота: они приходят как `web_app_data` в сообщении пользователя.

Формат заказа:

```json
{ "v": 2, "items": [ { "s": "раздел", "t": "товар", "o": "вариант", "p": 1200, "q": 2 } ] }
```
